# 쇼츠콘 설치 파일

수강생용 쇼핑 쇼츠 제작 앱 **쇼츠콘**의 설치 파일 배포 저장소입니다(자동 업데이트용). 소스는 들어 있지 않습니다.
설치 뒤 수강 신청 때 쓴 이름·전화번호로 수강생 확인을 해야 쓸 수 있습니다.

## Windows
[Releases](../../releases/latest)에서 `ShortsCon-<버전>-Setup.exe` 를 받아 실행하세요.

## macOS (Apple 실리콘 M1 이상)
터미널에 아래 한 줄을 붙여 넣고 Return:
```
curl -fsSL https://raw.githubusercontent.com/AImongs/ShortsCon-releases/main/install-mac.sh | sh
```
(브라우저로 받은 앱은 Apple 공증이 없어 "손상되었기 때문에 열 수 없습니다"가 뜹니다 — 위 명령으로 설치하세요.)
